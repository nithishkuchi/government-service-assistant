SERVICE NAME: PAN Card New Application

OVERVIEW:
This service helps a first-time applicant apply for a new PAN card. The user can apply online by themselves or take help from a net centre, MeeSeva, or CSC operator. This guide is meant for normal adult applicants applying for a new PAN card for the first time.

WHO IS THIS FOR:
- First-time PAN applicants
- Students who need PAN for education, scholarship, banking, or jobs
- Adults who do not yet have a PAN card
- Users in villages, mandals, towns, and cities
- Users who may need operator assistance

IMPORTANT NOTE:
If the user is not comfortable using a phone or computer, they can go to the nearest net centre / MeeSeva / CSC. The operator can fill the application for them. The operator may charge approximately ₹100 to ₹300 or more as service charge apart from official fees. Ask the service charge clearly before starting.

MAIN APPLICATION MODES:
1. Self-application online
2. Application through net centre / MeeSeva / CSC operator

Expected result:
You are fully ready to start the PAN application without interruption.

Decide whether to apply by yourself online or through an operator.

COMMON ERRORS AND EXACT SOLUTIONS
==================================================

Problem: OTP not received
Solution:
- Wait for some time
- Check mobile network
- Ensure correct mobile number is entered
- Use resend OTP
- If Aadhaar-linked mobile is inactive, choose another allowed verification path or visit operator

Problem: Payment deducted but application not confirmed
Solution:
- Do not pay immediately again
- Wait for gateway update
- Check status using token/reference
- Check email/SMS
- Save bank transaction ID
- If still unresolved, contact support or operator

Problem: Name mismatch with Aadhaar
Solution:
- Enter name exactly as per supporting document
- Do not use short forms casually
- If mismatch is major, correct source document first or use proper proof set

Problem: Wrong document uploaded
Solution:
- If not yet submitted, replace the upload
- If already submitted and application is held/rejected, follow re-upload/correction instructions if available or reapply as needed

Problem: Signature upload failed
Solution:
- Use proper file size and format
- Sign on white paper with dark ink
- Scan clearly
- Crop properly
- Take operator help if repeated failure

Problem: Photo rejected or unclear
Solution:
- Use clear front-facing photo
- Ensure face is visible
- Avoid blur, shadows, and low resolution
- Reupload in correct size

Problem: Lost acknowledgement number
Solution:
- Check email
- Check SMS
- Check downloads/screenshots
- Ask operator
- Use portal recovery options if available

Problem: Application on hold
Solution:
- Read the reason carefully
- Correct document mismatch or upload issue
- Complete pending verification
- If needed, take help from operator or support channel

Problem: User does not know English
Solution:
- Use voice assistant guidance in local language
- Or visit nearest net centre / MeeSeva / CSC

==================================================
FAQ / USER DOUBTS
==================================================

Question: Can a student apply for a PAN card?
Answer:
Yes. A student can apply for a new PAN card if they need it for banking, scholarship, financial transactions, or future employment.

Question: Can I apply from a mobile phone?
Answer:
Yes, but using a laptop or net centre may be easier if document upload or payment becomes difficult.

Question: Is Aadhaar mandatory?
Answer:
Aadhaar is commonly used and very helpful, especially for OTP/eKYC, but the exact accepted proof depends on the application path.

Question: Can I do this fully online?
Answer:
Yes, in many cases the process can be done online, depending on the verification path and document requirements.

Question: Can I use a net centre?
Answer:
Yes. This is strongly recommended for users who are not comfortable with online forms or uploads.

Question: What should I do after submission?
Answer:
Save acknowledgement, complete OTP/eSign if asked, and track status regularly.
